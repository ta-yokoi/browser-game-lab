# こもれび — あそびのにわ

3歳半ごろのお子さまと親子で遊ぶ、9種類のオリジナル知育ゲームです。
HTML・CSS・JavaScriptと共通のSVGのみで動き、外部ライブラリ・通信API・ログインは使いません。
市販教材の問題やイラストは使用していません。

## あそび

| ゲーム             | やさしい      | ちょっとむずかしい |
| ------------------ | ------------- | ------------------ |
| おなじもの         | 6択             | 8択                    |
| かずあそび         | 7〜12個を運ぶ   | 足し算で求めた12〜18個を運ぶ（カウンターなし） |
| かたちあわせ       | 4つの枠へ運ぶ   | ひし形・六角形を含む6つの枠へ運ぶ |
| おおきい・ちいさい | 4つを小さい順に | 5つを大きい順・小さい順に |
| つぎは なあに？    | AABの規則       | ABACの規則（両方にダミー選択肢あり） |
| えあわせ           | 5組10枚         | 6組12枚                 |
| ほしの おさんぽ   | 6つの点をなぞる | 8つの点をなぞる         |
| えの パズル       | 6ピース         | 9ピース                 |
| おとの まねっこ   | 5音を再現       | 7音を再現               |

果物・並べ替え・パズルはマウスや指でドラッグできます。ピースを選んで置き場を押す方法もあり、キーボードでも操作できます。星つなぎは指で線をなぞり、音のまねっこは光ったパッドの順番を再現します。音がオフでも光だけで遊べます。

トップ画面にはCSSによる庭の揺れ・浮遊・カードの登場演出があります。「動きを減らす」設定ではアニメーションを止めます。外部フォント・写真・動画・アニメーションライブラリは使わず、共通SVGとWeb Audioを再利用しています。

最初は保護者の方と一緒に遊んでください。各ゲーム下の「おうちの方へ・むずかしさ」で難易度を変更できます。変更すると最初から始まります。
時間制限・点数の競争・ゲームオーバーはありません。間違えても何度でも選び直せます。
絵合わせ以外は5問で一区切りです。正解すると自動で次の問題へ進みます。絵合わせは全組が揃ったら自動で終了します。

## 正解の表示と音

正解1問につきシール1枚（絵合わせは1ペアにつき1枚）をもらえます。トップ・各ゲームの「シールちょう」で、ゲーム別・難易度別の累計、最後まで遊んだ回数、1・5・10・25・50・100枚の記念シールを確認できます。同じ端末・ブラウザのlocalStorageに保存し、再読み込み後も残ります。別端末への共有はなく、ブラウザデータを削除すると消えます。保存できない場合はページ内だけで集められます。追加前の実績は遡って記録しません。

すべてのゲームで正解すると、大きな赤丸を表示して約1.4秒後に次の問題へ進みます。絵合わせではペアが揃ったときに約1.8秒表示します。赤丸はタップ操作を遮りません。

各ページ上部の「おと」ボタンで、BGMと効果音をまとめてオン／オフできます。初期状態はオンです。実際の再生は最初のタップ・クリック・キー操作で開始します。設定はlocalStorageに保存し、ページ移動・再読み込み後も引き継ぎます。保存できない環境でもそのページ内の切り替えは利用できます。
BGMはゆっくりしたオリジナルの旋律、正解は上がるチャイム、不正解は小さくやわらかい音です。Web Audio APIで合成するため、音楽ファイルやダウンロードはありません。
ページが非表示になると音を停止し、戻ってタップ・キー操作をすると再開します。音声機能が利用できない環境でもゲームは遊べます。

## 公開

公開先: https://ta-yokoi.github.io/browser-game-lab/

`main`へpushするとGitHub Actionsが構文チェック・問題生成と音声制御のテスト・ビルド・公開を実行します。
PRではチェックとビルドのみ実行します。PRの変更はmainにマージするまで公開されません。
`site/`がソースで、`dist/`は公開用コピーです。生成物はコミットしません。

## ローカルで遊ぶ

必要なもの: Node.js 22以上、Python 3。作成時の環境ではNode.js 24、Python 3が利用可能でした。
依存パッケージがないため、`npm install` は不要です。

```sh
cd /Users/takamichiyokoi/70_openx/10_git_game
npm run dev
```

ブラウザで http://127.0.0.1:5173 を開きます。終了は `Ctrl+C`。
ソースを変更したらブラウザを再読み込みしてください。

```sh
npm run check
npm run build
npm run preview
```

公開用のファイルは `dist/` に生成されます。プレビューは http://127.0.0.1:4173 です。

## 検証

`npm run check` は `site/`、`scripts/`、`tests/` 内のすべてのJavaScriptの構文、セットアップ用シェルの構文、問題生成と音声制御のテストを確認します。
`npm test` では問題生成と音声制御のテストを実行します。
問題は各難易度で繰り返し生成し、正解が1つだけ存在すること、数の範囲、3〜4種類の並び、絵合わせのペア数を検証します。
音声制御は初期ミュート、連打制限、停止・再開、非対応環境、音声準備中のオフ切り替えを検証します。

ブラウザで確認する項目:

- トップページから全ゲームへ移動し、ホームに戻れる
- 各ゲームの正解・不正解・5問終了・再挑戦・難易度変更
- 形をドラッグして枠に合わせる操作と、タップ・キーボードでの代替操作
- 絵合わせの開始前表示、不一致中の連打防止、全組完成
- 難易度変更時に待機中の処理が残らない
- スマートフォン縦画面（幅320〜390px）とPC、キーボード操作

## ファイル構成

```text
site/
  index.html                 ゲーム一覧
  home.js                    一覧カードの描画
  style.css                  全画面共通のスタイル
  assets/pictures.svg        再利用するオリジナルSVGイラスト
  games/<ゲームID>/index.html 各ゲームの入口（9種類）
  shared/catalog.js          ゲーム説明・絵の名前
  shared/art.js              SVG描画
  shared/audio.js            容量を増やさないBGM・効果音の合成
  shared/questions.js        問題・カードの生成
  shared/play.js             共通の進行・操作処理
  shared/hands-on.js         ドラッグ・なぞり・組立・音まねの操作
scripts/
  check.mjs                  JavaScriptの再帰的な構文チェック
  build.mjs                  公開用ファイルの生成
  setup-github.sh             初回のリポジトリ・Pages設定
tests/questions.test.js      問題生成のテスト
tests/audio.test.js          音声制御のテスト
.github/workflows/pages.yml  自動検証・公開
```

## 普段の更新

```sh
npm run check
npm run build
git add site scripts tests package.json README.md
git commit -m "Update learning games"
git push
```

作業ブランチからmainへPRを作成し、確認してマージしてください。
画像は共通SVGを再利用し、外部フォント・画像のダウンロードは行いません。
ブラウザの「動きを減らす」設定に対応しています。
シールの実績は端末内に保存します。個人情報の収集や実績の外部送信は行いません。

GitHub Pagesの設定は Settings → Pages → Source → GitHub Actions を使用します。
既存リポジトリでは初回セットアップ用スクリプトを再実行する必要はありません。
